全球顶尖 AI 工具选型（2026）

大分子研发 · 临床创新药 · 演示文稿生成 — 按场景选最强，点名称进入官网

一、大分子研发

科学底座（结构 / 设计）与成药商业平台分开选。自研常见组合：结构预测 → 从头设计 → 序列设计 → 湿实验闭环。
工具类型最强点
Isomorphic IsoDDE 结构预测 难抗体–抗原界面，公开报道领先 AlphaFold 3 / Boltz-2，CDR-H3 更强
AlphaFold 3 结构预测 复合物结构行业基准，多数团队默认起点
RFdiffusion / RFAntibody 从头设计 指定表位从头抗体，冷冻电镜验证，开源
ProteinMPNN 序列设计 给定骨架后的序列设计标准下游步骤
Chai-2 · ESM3 · Boltz-2 生成 / 开源 全原子生成、序列–结构–功能联合、AF3 开源路线
Absci Origin-1 商业闭环 零先验表位从头抗体，设计–实验短闭环
Generate:Biomedicines 商业闭环 治疗性蛋白生成式设计，药企合作
BigHat · Cradle 优化 亲和力 / 可开发性 / 人源化，用实验数据迭代
Schrödinger 企业装机 物理 + ML，小分子与大分子，药企装机率高

二、临床创新药研发

发现端（靶点→候选）与试验执行端（方案 / 入组 / 统计）分开选型，没有“一个 AI 生成新药”的万能工具。
工具阶段最强点
Isomorphic Labs 发现 AF 之上药物设计引擎；礼来、诺华等合作
Insilico Pharma.AI 发现→IND 靶点到 IND；进入人体试验的 AI 药物项目多
Recursion 发现 表型组学 + 化学设计，机制不清时的大规模筛选
Medidata 试验执行 EDC、方案优化、可行性、合成对照；全球装机最广
Unlearn 试验设计 患者数字孪生；PROCOVA 获 EMA 资格认定
Owkin 生物标志物 多模态数据、外部对照；肿瘤 / 免疫更强
Tempus · Flatiron RWD 肿瘤真实世界数据：入组、亚组、外部对照
Phesi Trial Accelerator 可行性 国家 / 中心 / 研究者 / 患者可行性
  • 推荐组合：发现用 Isomorphic 或 Insilico；方案与入组用 Medidata；缩小样本量用 Unlearn；标志物 / 外部对照用 Owkin 或 Tempus。

工具场景说明
